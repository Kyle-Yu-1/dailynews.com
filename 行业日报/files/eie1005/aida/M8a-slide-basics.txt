Sometimes special graphics are needed
and Boolean operations can be used to
manipulate shapes.
Boolean operations involve logic
deductions using symbols including
union, intersection, subtraction, and so
on. They are often used in graphic
processing operations and can quickly
combine new shapes.
The first type is union, which merges
two shapes into one.
The second type is intersection, which
combines two shapes into a new shape by
cutting out the intersecting part.
The third type is subtraction, which
splits two shapes into several new
shapes.
The fourth type is exclusion, which
retains the overlapping part of two
shapes.
The fifth type is division, which
removes the part of the first shape that
intersects with the second shape.
