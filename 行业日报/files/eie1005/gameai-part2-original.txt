What is Reinforcement Learning?
• Reinforcement Learning – an agent (an AI) will learn from the 
environment by interacting with it (through trial and error) and 
receiving rewards (negative or positive) as feedback for 
performing actions
• Commonly used in game AI development
• Different from supervised and unsupervised learning
• Supervised learning: A child is put in a school to learn from teachers 
who always give answers to students
• Unsupervised learning: A child is put in a school and learns only 
from books and exercises with no teachers and answers
• Reinforcement learning: A child is put in the working place to learn 
in the working environment!

Introduction to Q-Learning
• Q-Learning is a reinforcement 
learning method that will find the 
next best action for an agent, given 
a current state
• Q comes from “the Quality” of that 
action at that state
• A Q-table is kept in the method 
that indicates the quality (Q value) 
of every move of the agent at 
every state
• The Q-table is updated for each 
move. With sufficient exploration 
and training, the Q-table converges 
towards the optimal action values.

The Bellman equation
• The Bellman equation
15
New Q-value = Original Q-value + 
{ Reward of the action + Possible increase of Q-value due to this action}
• Does not only rely on the immediate reward, look also to 
the future 
• Ask the question: Would the current action bring to higher 
Q-value in the future based on experience?
• If yes, New Q-value has a higher value. Thus endorse the 
current action
• If no, New Q-value has a lower value. Thus discredit the 
current action

Deep Q-Learning
• Q-Learning works well with small 
number of states and actions
• The Q-table will be incredibly large 
for modern computer games 
• Rather using table lookup, deep Q-
learning uses a deep neural network
to generate the Q-value
• Approximate, given a state, the 
different Q-values for each possible 
action at that state
• Deep Q-Network can handle large 
state spaces by approximating Q-
values with a neural network; GPUs 
accelerate both training and 
inference
