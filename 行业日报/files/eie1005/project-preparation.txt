Part I: Introduction of Teachable Machine


In this section, we are going to introduce and teach you how to get started with Teachable


Machine (https://teachablemachine.withgoogle.com/). Teachable Machine is a web-based tool


that makes creating machine learning models fast, easy, and accessible to everyone. We can use


it to create an AI model for our own image recognition without any expertise or coding skills.


1.
 
Get started with Teachable Machine


Open
 
the
 
Teachable
 
Machine
 
(https://teachablemachine.withgoogle.com/)
 
with
 
a
 
web


browser.


Fig 1. The interface of Teachable Machine Website


2.
 
Create a new image project


Click the “Get Started” button to create a new project.


After clicked the “Get Started” button, three options can be chosen:


i)
 
Image Project: train an AI model to classify different images using files or your


webcam.


ii)
 
Audio Project: train an audio-based AI classification model by sound waves


iii)
 
Pose Project: train a model to classify body positions using files or striking poses in


your webcam.


In this workshop, we focus on “Image Project”.

d) In the “Under the hood”, open the “vocab”. Some definitions and training setting can be

Training samples
: 85% of the uploaded samples are used to train the model


Testing samples:
 
the remaining 15% of the uploaded samples are never used to train

e) Also, more training details, such as “Accuracy per epoch” and “Loss per epoch”, are


plotted.


Accuracy per epoch
: accuracy is the percentage of classifications that a model gets


right during training.
 
If you model classifies 80 samples right out of 100, the accuracy


is 80/100 =0.8.
 
If the model’s prediction is perfect, the accuracy is one; The graph


potted here shows accuracy at each epoch. It is noted that the trained model will predict


the class with the highest probability as output for a sample and check it match with its


label (class name) or not.


Loss per epoch
: Loss is a measure for evaluating how well how well the model has


learnt from samples to predict the right classification results. If the model’s prediction


is perfect, the loss is zero; otherwise, the loss is greater than zero.
 
When the model


learning process is improving, the loss will decrease.
