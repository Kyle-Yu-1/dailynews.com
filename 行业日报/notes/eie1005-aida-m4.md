# EIE1005 · AIDA 模块 4 · 计算机视觉与模式识别

## ⏱ 30 秒速览
一句话：**CV = 让机器从图像/视频提取有意义信息**；**PR = 从任意数据（图/文/音）中找模式用于分类**——PR 的输入域比 CV 更广。
三条结论：① 视觉是人类第一信息通道（约 90% 大脑信息、93% 人际沟通）；② CV 历史：数字图像处理 → 模式识别 → 深度学习（2020+）→ 视觉+语言融合；③ 计算机"看"图像 = 看**数字矩阵（像素值）**。
关键词：computer vision, pattern recognition, pixels, classification, recognition。

## 一、为什么视觉重要
- 约 **90%** 传给大脑的信息是视觉；**93%** 的人类沟通经视觉形式完成。

## 二、什么是计算机视觉
- 多个定义，核心两条：① 自动识别图像/视频中的物体；② 通过视觉感知理解世界（模拟/增强人眼）。
- 目标：写出能**解读图像并"讲故事"**的程序（图里有什么、在哪里、什么关系、场景关系）。

## 三、历史
- 始于 1970 年代之前（50+ 年）；阶段：数字图像处理 → 模式识别 → 深度学习（2020 前后）→ 视觉与语言融合。
- 计算机眼中的图像 = **数字矩阵（像素值）**，处理的就是这些数。

## 四、CV vs PR 对比（必考）
| | Computer Vision | Pattern Recognition |
|---|---|---|
| 定义 | 训练机器从**图像**中提取有意义信息 | 识别数据中的模式/规律，用于**分类** |
| 输入数据 | 视觉数据（数字图像、视频） | 图像、文本、视频、音频……不限 |
| 目的 | 理解图像中可识别的特征 | 从样本中提取有用信息 |
| 应用 | 无人驾驶、医学诊断、畜牧监控、缺陷检测 | 计算机辅助诊断、生物信息学、数据压缩、图像分析、信号处理 |

## 五、Take-home 三要点
1. CV/PR 是活跃领域，几乎影响生活与社会每个层面，各专业都能找到应用。
2. 很多现在看到的系统诞生不到 5 年，领域变化极快。
3. 未来 5–10 年更多新应用（个人/社区/城市/国家尺度），大公司重兵投入。
