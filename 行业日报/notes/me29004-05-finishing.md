# ME29004 第 5 课 · 表面处理（Surface Finishing）

## 工作坊内容
- 关键工艺：**砂纸打磨 sanding、蒸气抛光 vapour polishing、喷涂 spray coating**。
- 实用测试：**摩擦测试 friction test 与粗糙度测试 roughness test** 评估表面质量。
- 目标：改善外观与功能（抓取纹理、减摩、防腐蚀）。

## 要点
1. **打磨**：目数越大越细；由粗到细逐级递进（如 120→240→400→800→1200），不跳级；方向一致。
2. **蒸气抛光**：溶剂蒸气使表层塑料微熔流平，适合 ABS 等，需通风。
3. **喷涂**：清洁 → 底漆 → 薄喷多层；附着力取决于表面清洁与底漆。
4. **测试**：粗糙度 Ra 越小越光滑；摩擦系数 μ 影响抓取与滑动。
5. 本项目应用：瓶盖夹爪接触面做纹理防滑，运动面减摩。

## 完整课件要点（2627_TM1326_SE · 14 页 · 2026/27）

### 一、四种工艺一句话
| 工艺 | 一句话 | 关键参数/材料 |
|---|---|---|
| **Sanding 砂纸打磨** | 去层纹、平滑、打底 | 120–220 粗 → 400 中 → 800–1000 细 → 湿磨 |
| **Sand blasting 喷砂** | 除锈除污、增粗糙度提附着力、做哑光 | 磨料：Aluminum oxide / Glass beads / Steel grit |
| **Vapour polishing 蒸气抛光** | 溶剂蒸气溶解表层平滑打印件 | ABS/ASA/PLA/nylon/TPU/PC |
| **Spray coating 喷涂** | 外观 + 耐久 + 调摩擦 | 三层：primer + paint + clear coat |

### 二、Sanding 细节（P5）
- 缺点四连：Time-Consuming（耗时）/ Manual Effort（费力易疲劳）/ Risk of Over-Sanding（变形磨平细节）/ Limited for Intricate Parts（难进细小缝隙）。
- 口诀：**粗→中→细→湿磨**，不跳目数。

### 三、Vapour polishing 细节（P7–P8）
- 五目的：溶平阶梯结构 / 减层纹 / 高光外观 / 降低活动件摩擦 / 为后续工艺准备。
- 三步骤：溶剂蒸气腔暴露 → 蒸气软化平滑 → 晾干硬化。
- **过度抛光四害**：Deformation（变形）· Loss of Detail（丢细节）· Cracking（变脆开裂）· Sticky Surface（发粘吸尘）。

### 四、Friction test 与 Roughness test（P10–P11）
- **摩擦定义**（背英文）：Friction is a force that opposes motion between two surfaces in contact。
- **四因素**：Surface roughness / Material type / Weight(force) / Lubrication。
- 摩擦日常五例：行走防滑、刹车、抓握、擦火柴、驾车抓地。
- **Roughness test**：粗糙度仪（profilometer）探针扫表面记录峰谷；影响摩擦磨损、外观手感、零件配合。

### 五、安全（P3，本课评估含 MC 或安全题）
- 未授权不开机、不离开运转中的机器、车间内不玩/跑/吃喝。
- 长发扎起；禁宽松衣物与项链/围巾/手镯/手套；戴 PPE。
- 化学品容器用后盖紧；**溅入眼/皮肤：清水冲 15 分钟**。

### 六、本项目实践（P12）
- 3D 打印件三件套：**Sanding → Vapour polishing → Painting**。
- 学习安排：30min 讲解 + 45min 演示 + 15min 休息 + 60min 练习 + 30min MC 评估。

## 🧠 拓展（外部权威资料，检索于 2026-10-06）

### 1. 砂纸目数 ↔ 表面粗糙度 Ra
> 🧠 拓展（外部资料，检索于 2026-10-06）：目数越大 Ra 越小，但细磨到一定目数后 Ra 趋于稳定。实验数据（Nature Sci. Rep. 2019，打磨基板）：1500 Grit → Ra ≈ 1.02 μm；600 Grit → Ra ≈ 1.03 μm；220 Grit 与 120 Grit 则更粗糙——即 600 目以上再细磨收益递减。
> 🌐 来源：https://www.nature.com/articles/s41598-019-51490-5 · 换算：1 microinch = 0.025 μm（finishing.com）。

### 2. 蒸气抛光的溶剂-材料-温度对照
> 🧠 拓展（外部资料，检索于 2026-10-06）：蒸气抛光机理=溶剂蒸气溶解 ABS/PLA 表层聚合物，表面链段流动流平后溶剂蒸发，留下更光滑表面。典型参数：**ABS 用丙酮（acetone），抛光温度约 56°C；PLA 用四氢呋喃（THF），约 66°C**（温度取溶剂沸点附近）。
> 🌐 来源：Tribology in Industry 2022（tribology.rs/journals/2022/2022-4/2022-4-01.html）· Springer Progress in Additive Manufacturing 2022（s40964-022-00391-7）。
> 📖 译注：课件说"不同材料用不同溶剂"，此处给出具体对应；实验室采用超声雾化（ultrasonic mist maker）的低成本蒸气腔方案。

### 3. 喷涂的三层结构与厚度
> 🧠 拓展（外部资料，检索于 2026-10-06）：汽车/工业喷涂标准流程 = **primer（底漆）→ base coat（色漆）→ clear coat（清漆）**，每层喷涂后经 flash-off（闪干区）再进烘箱；clear coat 干膜厚约 1.0–3.0 mil（≈ **25–75 μm**）。
> 🌐 来源：欧盟 JRC《表面处理最佳可行技术参考（STS BREF）》2020（eippcb.jrc.ec.europa.eu）· US 专利 US20070110902A1。

### 4. 常用材料摩擦系数（数量级参考）
> 🧠 拓展（外部资料，检索于 2026-10-06）：静/动摩擦系数典型值——**钢-钢 0.74 / 0.57；铝-钢 0.61 / 0.47；橡胶-混凝土 ≈ 0.8；木-木 0.25–0.5；铸铁-铸铁 0.10–0.15（干）**。课件四因素（粗糙度/材料/正压力/润滑）与手册一致：润滑可使 μ 降到 0.1 以下。
> 🌐 来源：EPA 工程摩擦系数表（epa.gov）·《Elements of Machine Design》（HathiTrust）· ScienceDirect Static Coefficient 综述。

### 5. 进阶工艺（了解即可）
> 🧠 拓展（外部资料，检索于 2026-10-06）：除蒸气抛光外，聚合物打印件还可用**激光抛光**：FDM 件以 7 J/cm² 能量密度处理后 Ra 降约 95%（最终 ≈1.9 μm）；功率过高会因聚合物熔点低而过熔。
> 🌐 来源：Nazarbayev University 综述（nur.nu.edu.kz）· Perez Deway & Ulutan 研究。

### 📋 速记表（考前 10 分钟过一遍）
| 考点 | 记这一句 |
|---|---|
| Ra / Rz / Rq | Ra=平均、Rz=峰谷、Rq=均方根；**Ra 会把深划痕"平均掉"，看划痕要 Rz** |
| 目数 | 数字越大越细；FEPA P 级与 CAMI 换算：**P1200 ≈ CAMI 600** |
| 三种磨料 | 氧化铝=强力除锈/粗化；玻璃珠=温和清洁/哑光；钢砂=重载钢件 |
| 湿磨 | 水带走屑粒：**防堵纸、少划痕、降温、少尘** |
| 摩擦系数测量 | **μ = F/N**；斜面法 **μ = tanθ**（刚好开始滑动的角度） |
| 粗糙度 ↔ 摩擦 | **不是越滑越小**：太滑粘着、太糙互锁，先降后升有最优区间 |
| 喷漆三缺陷 | 橘皮=雾化差/太远；流挂=太厚/太近；干喷=太远/半干 |
| 附着力 | 清洁+粗化+底漆；低表面能塑料要电晕/等离子；**划格法 ASTM 5B 最好、ISO 0 最好（编号相反）** |

### 6. 三个粗糙度参数：Ra、Rq、Rz
> 🧠 拓展（外部资料，检索于 2026-10-06）：**Ra**（Roughness Average，轮廓算数平均偏差）最常用，但它是"平均值"——一道深划痕会被周围大面积平地稀释，所以 **Ra 相同不代表表面一样**。**Rq**（均方根）把高低点平方后再开方，对个别尖峰更敏感；**Rz**（最大峰谷高度，ISO 4287 中 Rz = Rp + Rv）直接反映最高峰与最深谷，对划痕、裂纹、应力集中最敏感。工程上常要求 **Ra 与 Rz 同时给出**。
> 🌐 来源：ISO 4287；Keyence 表面粗糙度参数说明（keyence.com）。
> 🎯 考法：给两张剖面图 Ra 相同，问哪张更容易藏污纳垢/应力集中 → 看 Rz。

### 7. 目数的两种标准：FEPA「P 级」与 CAMI「数字级」
> 🧠 拓展（外部资料，检索于 2026-10-06）：欧洲 FEPA 标准用 P 前缀（P400/P600），美国 CAMI 用纯数字（360/400），两者**不能直接划等号**。同颗粒细度下 P 级数字约是 CAMI 的两倍：**P1200 ≈ CAMI 600（≈15–16 μm）；P600 ≈ 25.8 μm，介于 CAMI 360–400 之间**——即「P600 比 CAMI 600 更粗」。课件未标标准，大概率只考「数字越大越细、不跳级」；若出现 P 级对照，用上面这条换算。
> 🌐 来源：FEPA/CAMI 磨料对照表（mtixtl.com；Fine Woodworking）。

### 8. 三种喷砂磨料怎么选（对比表）
| 磨料 | 形状/硬度 | 用途 | 特点/风险 |
|---|---|---|---|
| **Aluminum oxide 氧化铝** | 尖角、硬 | 强力除锈/除漆/表面粗化 | 可循环 10–12 次；会改变尺寸，不适合精密件 |
| **Glass beads 玻璃珠** | 圆珠、温和 | 清洁不伤基材、缎面/哑光 | 可循环 9–12 次；几乎不减薄，适合铝/不锈钢外观件 |
| **Steel grit 钢砂** | 尖角钢粒 | 厚锈/铸件重载清理 | 很耐用；碎粒可能嵌入软金属、污染不锈钢 |

> 🧠 拓展（外部资料，检索于 2026-10-06）：选择逻辑 = 材料硬度 + 想不想减薄 + 目标粗糙度：精密外观件用玻璃珠，除厚锈用氧化铝/钢砂，做统一哑光用玻璃珠。
> 🌐 来源：IST Abrasive Media Selection Guide（istsurface.com）。

### 9. 湿磨 vs 干磨（课件「湿磨更佳」的完整理由）
> 🧠 拓展（外部资料，检索于 2026-10-06）：水/润滑液把磨下来的屑粒悬浮带走 → **砂纸不堵塞**（堵塞的砂纸不但效率下降，还会刮出深划痕）；同时**降温**（塑料受热变软会"糊住"砂纸）、**减少扬尘**（更安全）。缺点：怕水/会生锈的工件不能用，磨后要清洗。实操惯例：粗磨阶段干磨去料快，细磨收尾湿磨出镜面。
> 🌐 来源：StewMac 打磨指南（stewmac.com）；Homebuilding（homebuilding.co.uk）。

### 10. 摩擦系数怎么测：μ = F/N 与斜面法 μ = tanθ
> 🧠 拓展（外部资料，检索于 2026-10-06）：**水平拉测**——用测力计匀速拉动物体，读数即摩擦力 F，法向力 N = 重量，**μ = F/N**。**斜面法**——缓慢抬高斜面，物体**刚好开始滑动**时的倾角 θ，**μs = tan θ**（静摩擦）；给初速度让物体沿斜面匀速下滑可测动摩擦 μk。记住**同材料 μs > μk**：把物体推"动"比维持"动"更费力。本项目测夹爪抓力本质上就是一次 μ 实验。
> 🌐 来源：工程力学教材（archive.org《Elements of Mechanics》）；Santa Fe College 物理实验笔记。

### 11. 反直觉考点：表面不是越光滑摩擦越小
> 🧠 拓展（外部资料，检索于 2026-10-06）：摩擦由「**粘着 adhesion**」与「**互锁/犁沟 interlocking**」共同贡献。太光滑 → 真实接触面积增大 → 粘着摩擦上升（两块干净平板能"吸"在一起）；太粗糙 → 峰谷互锁上升。所以 μ–粗糙度曲线通常**先降后升**，存在中间"最优粗糙度"。文献：手指摩擦实验显示脊高超过约 **42.5 μm** 后互锁贡献迅速增大（Wear 2011）。这正解释课件的应用逻辑：夹爪要做**适度纹理**防滑，而不是抛光成镜面。
> 🌐 来源：ScienceDirect Wear（S0043164811002249）；TRB《Optimum Skid-Resistant Surfaces》。

### 12. 喷涂三大缺陷：橘皮 / 流挂 / 干喷
| 缺陷 | 外观 | 主要原因 | 对策 |
|---|---|---|---|
| **Orange peel 橘皮** | 表面像橘子皮 | 雾化差、喷枪太远、温度过高、溶剂挥发太快 | 调低粘度/气压、缩短喷距、低温环境喷涂 |
| **Runs / Sags 流挂** | 涂层下坠成泪痕 | 喷太厚、枪太近/移动太慢、涂料太稀、干燥太慢 | 薄喷多层、控制粘度与喷距 |
| **Dry spray 干喷** | 粗糙粉状、无光泽 | 漆雾到表面前已半干（枪太远/温度高） | 缩短喷距、降温、加缓干溶剂 |

> 🌐 来源：Eastwood / PPG 喷涂故障排查指南。

### 13. 附着力科学 + 划格法（Cross-cut test）
> 🧠 拓展（外部资料，检索于 2026-10-06）：附着力三要素 = **清洁（去油去脂）+ 粗化（机械互锁、增大接触面积）+ 底漆（改善润湿、防氧化）**。低表面能塑料（PE、PP、PTFE，约 29–36 mN/m）漆/胶很难润湿，须先**电晕 corona、等离子 plasma 或火焰处理**提高表面能（等离子处理后接触角可 ≤20°）。验收用**划格法**：划网格 → 贴胶带 → 撕下 → 看脱落面积。**注意两套编号方向相反**：ASTM D3359 是 **5B = 0% 脱落（最好）→ 0B = >65% 脱落（最差）**；ISO 2409 是 **0 = 最好、5 = 最差**。
> 🌐 来源：ASTM D3359 / ISO 2409；Tantec、Enercon 表面处理资料。

### 14. 答题模板：给瓶盖夹爪写表面处理方案
> 🧠 拓展（外部资料，检索于 2026-10-06）：按「位置 → 目标 → 工艺 → 理由」四步作答。
> - **抓取接触面**：目标增大 μ → 喷砂粗化或贴防滑纹理 → 理由：适度粗糙提高互锁摩擦（考点 11）。
> - **运动副/导轨**：目标减摩 → 打磨至细目数（600→1000）并润滑 → 理由：润滑可使 μ 降至 0.1 以下（第一批拓展 4）。
> - **外观件**：打磨 → 蒸气抛光 → 喷涂三层 → 理由：先溶平层纹，再上色漆+清漆防护。
> - **金属件**（如有）：喷砂除锈 → 防腐涂层 → 理由：喷砂增加涂层附着力（课件 P6）。
