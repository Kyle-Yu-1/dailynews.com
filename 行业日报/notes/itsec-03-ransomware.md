# IT 安全 第 3 课 · 勒索软件与电脑防护（Module 12/13/22/23）

## 什么是勒索软件 Ransomware
- 加密文件后索要赎金；传播途径：钓鱼附件、恶意链接、漏洞利用、破解软件。

## 防护
- 3-2-1 备份：3 份副本、2 种介质、1 份离线；备份要可恢复验证。
- 更新系统与软件；不装盗版/破解；杀毒与 EDR；陌生宏不启用。

## 中招后
- 断网隔离、不付赎金（不保证解密）、保留样本、找专业支持/上报，从备份恢复。

## Windows 电脑安全
- 开启 Windows 更新与内置防病毒、账号设强密码、防火墙、不装来源不明软件、UAC 提示认真看。
