# EIE1005 · AIDA 模块 8 · Slide 入门（IT 素养）

## ⏱ 30 秒速览
一句话：做幻灯片 = 先定**16:9** 尺寸、先用**思维导图**理逻辑，再控制**字体 ≤3 种、颜色 ≤3 种**，动画克制。
三条结论：① 无特殊要求一律 **16:9**（现代显示适配）；4:3 仅投影设备需要；② 高质量图片 > 大段文字，注意去水印、标注来源；③ 布尔运算 5 种：并集/交集/减除/排除/拆分，用于快速造形状。
关键词：16:9, 4:3, mind map (XMind), sans-serif (Microsoft YaHei), masking, Boolean operations, align, animation (fly in/float in/wipe/zoom)。

## 一、尺寸与准备
- 两种版式：**16:9**（默认推荐，适配现代显示）与 **4:3**（老投影设备）。设置：Design→Slide Size。
- **先画思维导图/草图再动手**（推荐工具 XMind）：幻灯片的核心是**逻辑 + 内容**，图先行能防遗漏。

## 二、图片、字体、配色
- 图片：高质量、与主题一致、无水印、网络图要**标注来源**；纯文字显得枯燥。
- 字体：用**无衬线 sans-serif**（如微软雅黑 Microsoft YaHei、Arial）；衬线字体（Times New Roman）笔画有装饰、粗细不一；**字体种类 ≤3 种**并保持统一。
- 配色：**≤3 种颜色**，多了视觉疲劳；拿不准参考配色网站。

## 三、进阶技巧
- **蒙版 masking**：图片过亮时，盖一层黑色矩形并调透明度压暗。
- **布尔运算 Boolean operations**：并集（合并）、交集（保留重叠）、减除（去掉与第二形状相交部分）、排除、拆分——快速合成新形状。
- **对齐 Align**：Format→Align，例：三矩形「顶端对齐 + 横向分布」。
- **动画**：常用 fly in / float in / wipe / zoom；**不要过于复杂突兀**，切换（transition）也要节制。

## 🎯 考点
- 推荐版式 16:9；无衬线字体例子与"≤3"原则；颜色"≤3"；布尔运算类型；动画克制的原则。
