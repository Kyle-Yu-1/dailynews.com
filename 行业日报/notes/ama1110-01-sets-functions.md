# AMA1110 第 1 课 · 集合、不等式与函数

## 集合 Set
- 表示法（列举/描述/区间）；并 ∪、交 ∩、差、补集。
- 实数集合 R、区间（开/闭/半开）、邻域概念是后面极限的语言基础。

## 不等式 Inequality
- 不等式性质（乘负数变号）；绝对值不等式 |x−a|<ε 的几何含义 = 到 a 的距离小于 ε。
- 解二次/分式不等式：画数轴 + 符号表。

## 函数 Function
- 定义域、值域、对应关系三要素；单射/满射/双射。
- 复合函数 f∘g 与定义域限制；反函数存在条件与求法。
- 奇偶性：偶 f(−x)=f(x)（关于 y 轴对称）、奇 f(−x)=−f(x)（关于原点对称）。
- 常见初等函数图像：幂/指数/对数/三角。
