## 课堂笔记（合并自 OneNote）

### 实数与集合符号
- Real Numbers 实数 = Rational Numbers 有理数（分数 p/q，q≠0）+ Irrational Numbers 无理数
- N 自然数集（部分教材含 0）、Z 整数集 Integers、Q 有理数集、R 实数集
- 区间 Interval：闭 [a,b]={x: a≤x≤b}；开 (a,b)={x: a<x<b}；半开 [a,b)={x: a≤x<b}

### 函数基本概念
- Function 函数 y=f(x)：每个输入 x 唯一确定输出 y
- Domain 定义域：使 f(x) 有意义的最大输入范围
- Range 值域：所有可能输出
- Graph 函数图像：满足 y=f(x) 的点集

### 多项式与有理函数
- Polynomial Function 多项式函数；Rational Function 有理函数 = 两个多项式之商
- Absolute Value Function 绝对值函数：图像为 V 字形
- 函数运算：和/差/积/商 Sum/Difference/Product/Quotient；Composite Function 复合函数

### 过拟合与欠拟合（贯穿整门课）
- Underfitting 欠拟合：次数过低，Bias 偏差高，拟合不足
- Overfitting 过拟合：次数过高，Variance 方差高，过度拟合训练数据
- Ideal Model 理想模型：平衡偏差与方差，训练集与测试集表现都好

### 二次不等式求解
- 图形法：抛物线开口方向定解集；因式分解法：求根后按开口定区间

### 考前速记
- 定义域：有理函数分母≠0；偶次根式被开方数≥0
- 易错：有理函数化简前先确定定义域；区间开闭符号；过拟合=偏差-方差失衡
- 重点练：二次不等式、定义域、复合函数
