## 1. 为什么前面的 Training set 有"特征",后面的 training data 没有?

- 前面(经典 PR):流水线有显式"特征提取"步骤,训练集 = 人工设计的「特征向量 + 标签」。
- 后面(神经网络 MNIST):训练数据 = 「原始像素 + one-hot 期望输出」,特征由隐藏层**自动学习**。
- 易错:784 个像素本身就是输入特征;区别是「人工设计(hand-crafted)」vs「自动学习(learned/hidden)」。训练本质 = 学权重 = 学会提取什么特征。

## 2. 人工算特征再分类,属于什么学习?

- 属于 **supervised learning(监督学习)**——有标签 ✅;
- 更精确地说,是其中"**人工设计特征**"的经典 PR 做法;
- 神经网络同样是监督学习,差别只在特征来源(人工 vs 自动)。

## 3. 经典 PR 与"社交网络分析"的关系

- 不是并列关系:社交网络分析是**场景/数据**,经典 PR 是**方法家族**;
- 经典 PR 两大家族:
  - 监督·分类:有标签(如 L2 的 MNIST);
  - 无监督·聚类:没标签(如 L1 的 Simple Social Network,K-means k=4)。
- 课件拿社交网络举例,是为演示 K-means 五步(定质心→归组→重算→再归→稳定)。
- 易错:真实社区发现 ≠ K-means;无监督 ≠ 不需要特征(仍需定义"相似度")。

## 4. 神经网络 vs 经典 PR

- 神经网络是经典 PR 流水线的"进化实现":经典 PR 把特征提取与分类拆开、特征靠人设计;神经网络把二者合并、端到端自动学特征。
- 对比:经典 PR 可解释、小数据可用、算力低;神经网络黑盒、吃数据算力、复杂任务更强。
- 易错:神经网络也是 PR/ML 一支(AI ⊃ ML ⊃ DL);"不需要特征"实为"不需要人工特征"。

## 5. 卷积 / 卷积神经网络 / 与社交网络的区别

### 卷积(Convolution)
- 小窗口(卷积核)在图上滑动,每个位置加权求和 → 特征图;
- 2D:(I∗K)(i,j)=ΣΣ I·K;四件套 = 核/步长/填充/特征图;
- 作用:检测局部模式,本质是**可学习的特征提取器**。

### 卷积神经网络(CNN)
- 用卷积层替代全连接层的神经网络,神经元只连局部(感受野);
- 结构:卷积层(卷积+激活)→池化→重复→展平→全连接→输出;
- 省参数两个原因:**局部感受野 + 权值共享(同一核整图复用)**;
- 课件例子:256×256 全连接 ≈196 万权重 vs 卷积核 k×k 个。

### CNN vs 社交网络(仅"网络"二字撞名)
- 社交网络 = 数据/图结构(节点=人,边=关系),用于社区发现等分析;
- 神经网络/CNN = 计算模型(节点=神经元,边=可学权重),用于分类/识别;
- 英文分别为 social network 与 neural network,含义无关。

## 6. 卷积神经网络的原理(手算版)

### 原理三句话
1. **卷积 = 滑动加权求和**:3×3 小窗口(卷积核)在图上逐格滑动,每个位置把窗口 9 个数与核 9 个权重相乘再相加,写进输出一格。
2. **核的数值决定"找什么"**:边缘核在平坦处算 0、在边缘处算大值 → 得到"哪里有这种模式"的特征图。
3. **CNN = 用滑动窗口代替全连接**的神经网络:核权重是训练学出来的;同一核滑遍全图(权值共享),参数比全连接少几十万倍;后面接池化(缩小)→展平→全连接→类别概率。

### 手工算一遍(竖边检测核)
输入 5×5"小山"图,核 = [-1,0,1; -2,0,2; -1,0,1]:
- 窗口最左:0×(−1)+1×0+2×1 + 1×(−2)+2×0+4×2 + 2×(−1)+4×0+8×1 = **+14**(左边"低到高"的边)
- 窗口正中:对称正负抵消 = **0**(平坦处无边缘)
- 窗口最右:**−14**(右边"高到低"的边)
→ 特征图 = [14, 0, −14; …],机器重复 9 次乘加就找到"哪里有竖边"。

### 记住三点
- **局部感受野**:神经元只看一小块;
- **权值共享**:同一核滑遍全图,参数不随图变大;
- **特征层级**:低层核找边角 → 中层找鼻子/眼睛 → 高层拼出"狗"。

### 6.1 补充:CNN 是"增加操作、减少存储"吗?(答:只对一半)
- ✅ 参数少(储存小)正确;❌ "增加操作次数"一般不对。
- 演示数字:全连接 5×5→3×3 = 225 权重、225 次乘加;卷积 3×3 = 9 权重、9×9=81 次乘加 → **同时省参数、省计算**。
- 真正的代价是"假设":特征局部 + 特征与位置无关(平移不变性)——对图像成立,对某些数据不成立。
- 深度 CNN 算力大是因为层多、通道多,不是卷积本身贵。
