# AMA1110 第 3 课 · 微分法则与洛必达

## 导数 Derivative
- 定义：f'(x)=lim [f(x+h)−f(x)]/h；几何意义 = 切线斜率；物理意义 = 变化率。

## 求导法则
- 基本公式：幂/指数/对数/三角/反三角。
- **乘积法则**：(uv)' = u'v + uv'
- **商法则**：(u/v)' = (u'v − uv') / v²
- **链式法则**：(f∘g)' = f'(g)·g'（复合函数由外到内逐层求导）

## 应用
- 单调性（f'>0 增）、极值（f'=0 + 变号）、凹凸性（f''）。
- 最优化问题：建立函数 → 求导 → 找临界点 → 端点比较。

## 洛必达法则 L'Hôpital
- 0/0 或 ∞/∞ 型：lim f/g = lim f'/g'（验证条件后再用，可多次）。
- 其他不定式（0·∞、∞−∞、1^∞）先变形再套。
