# ME29004 第 2 课 · 3D 打印（Practical 3D Printing）

> 工作坊内容：原理 → Shapr3D 建模 → 支撑与摆放 → Bambu Studio 切片 → 端执行器挑战。

## 工艺与原理
- FDM/FFF（本课用 Bambu）：热熔丝材逐层堆积；SLA/DLP 光固化；SLS 粉末烧结。
- 核心参数：层高（细=慢=光滑）、壁数、填充率（日常 5–20%）、首层与热床、材料（PLA/PETG/ABS/TPU）。
- 各向异性：层间最弱，受力方向尽量沿层内。

## Shapr3D 必会（马克杯练习）
Sketch（草图）→ Extrude（拉伸）→ Shell（抽壳）→ Fillet（圆角）→ 导出 STL。
其他成型：Revolve 旋转、Loft 放样、Sweep 扫描；编辑：Mirror 镜像、Chamfer 倒角。

## 支撑与摆放方向
- 45–60° 悬垂法则：超过就要支撑；短桥接可免支撑。
- 方向权衡：表面质量 vs 强度 vs 支撑量；能用倒角/旋转/拆分就不用支撑。

## Bambu Studio 流程
导入 STL → 摆放 → 支撑 → 层高/填充 → 切片预览逐层检查 → 床面调平清洁 → 首层观察 → 拆支撑去毛刺。

## 项目挑战
为瓶盖端执行器设计可打印的夹爪/支架，注意夹持面纹理与强度方向。

## 自测
