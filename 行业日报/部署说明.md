# 学习 Agent 网站 · 部署指南（大家都可以查看）

本站是纯静态站点：打开 `行业日报/index.html` 即本地可用；部署到任意静态托管后即可通过公网链接访问。

## 方式 A：GitHub Pages（推荐，免费、随仓库自动更新）
1. 在 GitHub 新建仓库，并把本仓库关联到远程：
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
2. 提交并推送（首次）：
   git add -A
   git commit -m "行业日报网站"
   git push -u origin master
3. 打开 GitHub 仓库 → Settings → Pages → Build and deployment 的 Source 选 **GitHub Actions**。
4. 仓库已内置 `.github/workflows/deploy-pages.yml`，会把 `行业日报` 目录发布为站点，几分钟后得到 `https://<用户名>.github.io/<仓库名>/` 链接。
5. 之后每天日报更新后，只需：
   git add 行业日报/data/reports.js
   git commit -m "日报更新 YYYY-MM-DD"
   git push
   站点会自动刷新。

## 方式 B：Netlify
- 拖拽部署：打开 app.netlify.com/drop，把 `行业日报` 文件夹整个拖进去即可。
- CLI 部署：npx netlify deploy --dir 行业日报 --prod
- 已提供 netlify.toml（publish 目录为站点根目录）。

## 方式 C：Vercel
- CLI 部署：npx vercel 行业日报 --prod
- 已提供 vercel.json（开启 cleanUrls）。

## 数据与行业目录
- 日报数据：`行业日报/data/reports.js`（window.DAILY_REPORTS 数组），由每日周期任务自动更新（每天首次打开 Codex 后自动整理），部署后自动出现在网站上。
- 行业目录：默认含“机器人”，每位访客可在网页左侧自行“＋ 添加行业”，该自定义列表保存在各自浏览器的本地存储中，不写入服务器，也不需要后端。
